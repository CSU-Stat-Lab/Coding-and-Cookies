1. Install R Download R from www.r-project.org. Click on “download R” (under Getting Started). Choose any CRAN mirror (typically cloud or USA location). Download R for your platform, then base: Binaries for base distribution. 2. Install RStudio Download RStudio from https://posit.co/download/rstudio-desktop/. We will use Direct Downloads (Open Source), RStudio IDE. Select the appropriate file for your platform.
